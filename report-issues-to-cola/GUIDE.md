# Cola 提 Issue 指南

## 快速开始

**第一步：让 Cola 加载规范**

对 Cola 说：

> 学习 https://github.com/marswaveai/cola-skills/tree/main/report-issues-to-cola 下的内容

**第二步：描述问题，让 Cola 提交**

用自然语言描述 Bug、需求或性能问题，Cola 会自动收集上下文、分类、打 Label、定优先级，并提交到 [cola-public-feedback](https://github.com/marswaveai/cola-public-feedback)。

> 如果 Cola 提示执行 `gh` 指令绑定 GitHub，跟随操作即可。

---

## 触发方式

在 Cola 桌面端对话中，直接描述问题后说"帮我提个 Issue"：

| 类型 | 触发示例 |
|------|----------|
| **Bug** | "这个回答不对"、"做错了"、"这不是我要的" |
| **Feature** | 描述你想要的功能 |
| **Perf** | "太慢了"、"卡顿"、"加载时间太长" |

---

## For Agent 的流程

### Issue 规范

#### 标题格式

`[Bug] xxx` / `[Feature] xxx` / `[Perf] xxx`

#### Labels

| Label | 层级 | 职责 |
|-------|------|------|
| `App` | 业务层 | 用户交互、UI、产品体验 |
| `Agent` | Agent 层 | 意图理解、任务执行、上下文管理 |
| `Infra` | Infra 层 | 工具开发、底层基建、稳定性 |

跨层问题打多个 Label，并在 Issue 中说明各层职责。

#### 优先级

| 优先级 | 含义 | 示例 |
|--------|------|------|
| `P0` | 阻断性，核心功能不可用 | 无法启动、数据丢失、安全漏洞 |
| `P1` | 严重影响体验，有 workaround | 主流程报错但刷新可恢复 |
| `P2` | 一般问题，不影响核心流程 | 回复格式偶尔不对、UI 细节 |
| `P3` | 改进建议，低优先级 | 体验优化、nice-to-have |

#### Bug 模板

> **核心原则：让开发者仅凭这个 Issue 就能复现问题。**

```markdown
## 复现步骤

1. 用户做了什么操作
2. 对 Cola 说了什么
3. ...

## API 请求与响应日志

请求：
- 接口：`POST /xxx`
- 请求体：（JSON）

响应：
- 状态码：xxx
- 响应体：（JSON 或错误信息）

## 补充信息

- 发生环境（OS 版本、网络状况等）
- 出现频率（必现 / 偶现）
- 相关截图或录屏
- 对根因的判断（如有）
```

#### Feature 模板

```markdown
## 需求描述与场景

要解决什么问题，在什么场景下使用。

## 期望行为

用户操作后应该看到什么结果。
```

#### Perf 模板

```markdown
## 问题描述

什么操作慢、卡顿或资源占用异常。

## 当前数据

| 场景 | 当前值 |
|------|--------|
| ... | ... |

## 目标

期望优化到什么水平。

## 瓶颈分析

对性能瓶颈的判断。

## 优化方向

可能的改进路径。
```

### 示例

#### Bug

用户说：

> "你刚才的回答完全跑题了，我问的是怎么部署，你在讲怎么开发。帮我提个 bug issue。"

Cola 提交：

> **[Bug] Agent 回复内容与用户问题不匹配**
> Labels: `Agent`, `P1`
>
> ### 复现步骤
> 1. 用户询问"如何部署到生产环境"
> 2. Agent 回复了开发环境搭建的内容
>
> ### API 请求与响应日志
> 请求：`POST /v1/chat/completions`，messages 最后一条为"如何部署到生产环境"
> 响应：回复内容涉及 `npm install`、本地开发配置，与部署无关
>
> ### 补充信息
> - macOS 14.2, Cola v0.3.1
> - 对话第 3 轮出现，前 2 轮正常
> - 可能是上下文混入了早期关于开发环境的讨论，干扰了意图识别

#### Feature

用户说：

> "我希望你回答的时候能显示你在想什么，像一个真人在思考那样。帮我提个 feature issue。"

Cola 提交：

> **[Feature] Agent 思考过程可视化**
> Labels: `Agent`, `App`, `P2`
>
> ### 需求描述与场景
> 用户与 Cola 对话时，希望看到 Agent 的思考过程，增强交互真实感。当前 Agent 直接输出回复，缺少"正在思考"的过渡体验。
>
> ### 期望行为
> Agent 回复前，以流式方式展示 thinking 内容，风格与当前 Mod 人设一致。
